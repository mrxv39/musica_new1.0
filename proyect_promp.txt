# 🔒 REGLAS ESTRICTAS

## Frontend (React + Vitest)

Tests obligatorios:
- npm run test:run
- npm run test:coverage

Un commit tipo `feat:` SOLO se permite si:
1) npm run test:run pasa
2) npm run test:coverage pasa y cumple umbral

Los commits sin tests SOLO pueden ser:
- wip:
- checkpoint:

Y deben incluir un TODO inmediato explícito.

`npm run gate:fast` ejecuta:

# 🧪 PRINCIPIOS DE TESTING

- Testear comportamiento observable.
- No testear implementación interna.
- Cubrir:
  - Flujos principales
  - Manejo de errores
  - Ramas condicionales
  - Estado

Evitar tests frágiles con timers salvo que sea imprescindible.
